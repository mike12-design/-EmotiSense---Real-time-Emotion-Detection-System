# 基于人脸识别的情绪关怀系统（EmotiSense）

---

## 一、论文摘要

### 中文摘要

如今，随着计算机视觉与深度学习的发展，基于视频流的人脸识别系统逐渐应用于智能陪伴、心理健康帮助以及人机交互等领域。传统的基于情感识别的关怀系统通常仅采用单一模型进行判定，容易受到光照、阴影等因素影响，识别准确率及鲁棒性均不高。此外，部分系统无法进行长期连续分析，缺乏主动反馈与情绪干预能力，难以满足实际应用需求。

本文研究的目的是通过多模型融合实现实时情绪识别。系统从摄像头获取视频流，在此基础上使用 YOLOv8 检测人脸并返回人脸属性信息，随后利用 OpenCV 对视频图像进行预处理，加载 HSEmotion 全局情绪模型和基于 ResNet 的眼部微表情模型进行特征提取，并利用元学习器进行决策融合，以提高系统在复杂环境下的情绪识别精度与鲁棒性。用户可通过浏览器访问系统，页面简洁，便于后续扩展。

该系统实现了用户登录、人脸识别、实时情绪识别以及情绪日记等功能，同时增加了音乐干预、语音安慰与分析功能。系统可持续对用户的情绪进行监测并做出智能反馈，使情绪识别系统更加智能化，对智能陪伴与心理健康辅助具有一定的应用价值。

**关键词**：计算机视觉，多模型融合，微表情识别，人脸情绪检测

### English Abstract

With the development of computer vision and deep learning, video stream-based face recognition systems are increasingly being applied to intelligent companionship, mental health assistance, and human-computer interaction. However, traditional emotion recognition-based care systems typically rely on only one model for judgment, making them easily affected by lighting conditions, shadows, and other environmental factors. Furthermore, some systems cannot perform long-term analysis simultaneously, lack proactive feedback and emotion intervention capabilities, and struggle to meet practical application needs.

This paper aims to achieve real-time emotion recognition using multi-model fusion. First, a video stream is acquired from a camera. Based on this, YOLOv8 is used to detect faces and return facial attribute information. Then, OpenCV is used to preprocess the video images, loading the HSEmotion global emotion model and a ResNet-based eye micro-expression model for feature extraction. Finally, a meta-learner is used for decision fusion. This improves the system's emotion recognition accuracy and robustness in complex environments. Users can access the system via a browser; the interface is simple, and future expansion is easier.

This system implements functions such as user login, face recognition, real-time emotion recognition, and emotion diary. It also incorporates music intervention, voice-based comfort, and analysis functions. This allows the system to continuously monitor users' emotions and provide intelligent feedback, making the emotion recognition system more intelligent and contributing to intelligent companionship and mental health.

**Keywords**: Computer Vision, Multi-Model Fusion, Micro-expression Recognition, Facial Emotion Detection

## 二、主要章节内容

### 第1章 绪论

**1.1 研究背景**

近年来情绪识别的研究逐渐走进生活，如心理健康咨询、智能陪伴、远程医疗及人机交互等。人们对实时心理活动的了解需求日益增多，个性化干预的需求正与日俱增。如何依靠技术对人的实时情绪进行跟踪并给出恰当反馈，成为当前研究的热点问题。

传统方法使用单模型或手工提取特征进行分类，在复杂光照、局部遮挡、微表情不明显等情况下识别率与鲁棒性较差，且缺乏连续分析和主动介入机制。

**1.2 研究意义**

技术上，验证多模型在易混淆情绪判别中的有效性，特别是中性和悲伤这两种容易混淆的情绪。验证全局面部特征与眼部局部特征结合的可行性。将情绪识别从"感知"拓展到"响应"，对智能陪伴、远程心理辅助等场景具有参考价值和实践意义。

**1.3 国内外研究现状与发展趋势**

- 国内：复旦大学王龑老师对静态和动态面部表情识别技术进行了归纳总结
- 国外：AffectNet、RAF-DB 等大规模公开数据集；DeepFace、HSEmotion、OpenFace 等开源工具；Konuk 等人提出 EfficientFER 模型
- 未来方向：多模态融合（视觉+语音+生理信号+文本语义）、引入注意力机制与对比学习、边缘设备实时推理、与大语言模型结合，从"理解情绪"发展到"响应情绪"

### 第2章 相关技术介绍

**2.1 Python**：高级解释型编程语言，简洁高效，广泛应用于人工智能、数据分析、Web 开发，支持面向对象编程。

**2.2 OpenCV**：开源计算机视觉库，负责摄像头视频流读取与图像预处理（缩放、颜色空间转换、帧读取等），支持多种操作系统。

**2.3 YOLOv8**：单阶段目标检测算法，在一次读取数据中同时完成目标定位与分类，用于实时人脸检测与定位，具有端到端训练与预测的优势。

**2.4 SQLite**：轻量嵌入式关系型数据库，所有数据保存在一个磁盘文件中，支持标准 SQL 和事务操作，无需独立数据库服务器。

**2.5 情绪平滑方法**：滑动窗口多投票机制，系统维护固定长度的预测序列队列，新增结果入队并移除最早结果，统计窗口内众数作为稳定输出。有效抑制"情绪闪烁"，是实际落地中情绪识别防抖动的重要保障。

**2.6 多模型融合**：
- 眼部 ResNet18 模型：K 折交叉验证训练，分层学习率微调（仅 Sad/Neutral 两类样本），224×224 像素输入
- 元学习器融合：从 HSEmotion 输出的 Sad、Neutral、Angry、Happy、Surprise 五类情绪概率，加上眼部模型输出的悲伤概率，拼接为 6 维特征向量，送入分类器进行 Sad/Neutral 二分类判断
- 对逻辑回归、支持向量机、随机森林及梯度提升树四种分类器比较后，选取准确率最优的逻辑回归作为元学习器
- 实验结果：Sad 与 Neutral 二分类准确率由 71.94% 提升至 72.80%，Neutral 召回率由 0.60 提升至 0.66

**3.2 系统运行环境**：Python 3.10、YOLOv8、OpenCV 4.11.0、SQLite 3.1

**3.3 系统功能需求分析**

- **用例图**：两种角色——管理员和普通用户
  - 普通用户：实时情绪监控、查看个人情绪历史统计、撰写与管理情绪日记、管理个人专属音乐库和安慰话术库
  - 管理员：推荐音乐库管理、话术库管理、推荐语录、全员资源管理、数据分析查看、日志查看、用户管理

- **模块流程图**（详见第四部分流程图描述）

**3.4 系统可行性分析**
- 技术可行：成熟开源技术栈，YOLOv8 + 多模型融合 + Vue 3 + FastAPI + SQLite
- 社会可行：心理健康需求增长，可应用于远程医疗、智能家居等领域
- 经济可行：全部基于开源框架，轻量级 SQLite 无需独立服务器，部署维护成本低

### 第4章 系统设计

**4.1 系统架构设计**

三层架构（详见第三部分系统结构）

**4.2 系统接口设计**

### 第5章 系统实现

**5.1 数据收集和模型训练**
- 数据来源：Facial Emotion Recognition Image Dataset，融合 IMDB、AffectNet 等公开数据集，包含多种光照条件和种族的中性与悲伤人脸图像
- 眼部模型训练：ResNet18 基础网络，224×224 输入，15 轮训练，保存为 .pth 格式
- 元学习器训练：抽取 Sad/Neutral 样本，提取 6 维特征，比较四种分类器后选取最优逻辑回归，保存为 .pkl 文件

**5.2 前端页面（10个）**：
- 登录页面：用户名密码认证，角色跳转
- 我的概览首页：当日情绪概览 + 月情绪饼状图 + 个人话术 + 心情日历
- 实时监控页面：人脸框 + 情绪标签 + 置信度分数，持续负面情绪触发干预
- 心情足迹页面：日/周/月折线图展示情绪变化趋势
- 日记管理页面：撰写日记，模型分析情绪与日记情绪不一致时以日记为准
- 系统设置页面：管理个人音乐库、安慰话术库、修改密码
- 数据分析页面（管理员）：高危干预预警 + 情绪动态轨迹 + 情绪分布饼图
- 用户管理页面（管理员）：用户 CRUD + 人脸特征录入（DeepFace VGG-Face 提取嵌入向量）
- 资源管理页面（管理员）：全局音乐/话术库统一管理
- 系统日志页面（管理员）：干预事件记录、检测人数、平均情绪

### 第6章 系统测试

对登录、情绪识别、资源管理、用户管理四大模块编写测试用例，全部通过：
- 登录功能：正确/错误密码、角色跳转、未登录拦截
- 情绪功能：摄像头连接、人脸检测、情绪识别、智能干预触发、数据库记录、无人脸处理
- 资源管理：音乐/话术的增删查
- 用户管理：用户 CRUD + 人脸录入 + 权限拦截

### 结论

本文主要工作：
1. 介绍了情绪识别技术及其在远程医疗、智能家居等方面的应用前景，从技术、社会及经济三个方面论证系统可行性
2. 对多模型融合方法进行详细说明。相较于单一模型，Sad 与 Neutral 二分类准确率由 71.94% 提升至 72.80%
3. 设计系统数据库，包含 7 张核心数据表，通过外键建立关联
4. 实现了情绪监测、历史统计、多图表分析、智能干预等核心功能模块
5. 对系统登录验证、情绪识别、资源管理及用户管理等模块进行测试，保证系统正常运行与可靠性

系统优势与不足：
- 优势：实时准确识别人脸情绪，利用情绪变化趋势实现智能干预，降低人工干预程度
- 不足：识别维度较单一（仅视觉，缺少语音/文本）；多人场景个体情绪识别能力有限；干预方式有限
- 展望：引入多模态识别通道，添加 AI 对话与陪伴功能，提高系统实用性

### 技术栈汇总

| 层级 | 技术 | 版本/说明 |
|------|------|-----------|

## 四、流程图描述

### 4.1 系统登录模块流程

```
用户访问系统 → 进入登录页面 → 输入用户名和密码
    → 后端查询数据库验证
    → 【验证通过】→ 根据角色跳转至管理员首页或用户首页
    → 【验证失败】→ 提示用户名或密码错误，返回登录页面
```

### 4.2 情绪监控模块流程

```
摄像头开启 → 系统加载视频流 → YOLOv8 实时检测人脸
    → 人脸区域送入情绪识别模块
    → HSEmotion 全局情绪识别 + 眼部微表情模型提取特征
    → 元学习器决策融合 → 情绪分类结果输出
    → 滑动窗口多投票平滑 → 显示情绪标签与置信度
    → 检测持续负面情绪 → 触发智能干预（音乐播放 + TTS 语音安慰）
    → 将情绪日志记录至 SQLite 数据库
```

### 4.3 视频流处理模块流程

```
摄像头捕获视频帧 → OpenCV 图像预处理（缩放/颜色空间转换）
    → YOLOv8 人脸检测 → 返回人脸边界框
    → 提取人脸区域 ROI
    → 区域 1（全脸）→ HSEmotion 全局情绪模型 → 5 类情绪概率
    → 区域 2（眼部）→ ResNet18 眼部模型 → Sad 概率
    → 拼接 6 维特征向量 → 元学习器分类 → 输出最终情绪
```

### 4.4 干预事件记录模块流程

```
情绪监控模块检测到持续负面情绪（20 帧窗口，70% 负面比例）
    → 情绪趋势分析子模块启动
    → 查询匹配情绪标签的音乐资源 → 播放背景音乐
    → 调用 TTS 引擎生成语音安慰 → 播放语音
    → 记录干预事件至 system_events 表（事件时间、检测人数、最终情绪、干预动作类型、关联资源 ID）
    → 120 秒冷却期，避免频繁干预
```

### 4.5 资源与用户管理模块流程

```
【管理员登录】
    → 用户管理：查看列表 / 添加 / 修改 / 删除用户 / 人脸录入
    → 资源管理：上传音乐（带情绪标签）/ 删除音乐 / 添加话术 / 移除话术
    → 数据分析：高危预警 / 情绪轨迹 / 饼图 / 四象限散点图
    → 日志查看：干预事件表格 / 检测人数 / 平均情绪

【普通用户登录】
    → 个人设置：管理个人音乐库 / 个人话术库 / 修改密码
    → 日记管理：撰写 / 修改 / 删除日记
```
